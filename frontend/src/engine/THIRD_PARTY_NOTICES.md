## GRAPE — `grape_core.py`

An instrumented copy of GRAPE's `grape.py`.

- Copyright (c) 2022-2023, BDS Research Group at University of Limerick
- License: BSD 3-Clause — [`LICENSES/BSD-3-Clause.txt`](../../../LICENSES/BSD-3-Clause.txt)
- Upstream: <https://github.com/BDResearchGroup/GRAPE>
- Paper: <https://www.mdpi.com/2624-6120/3/3/39>

**Modifications** (all documented in the file itself):

1. Every mapping step is recorded as a trace event, and an optional genome
   `wrap` was added — the instrumentation this project exists to provide.
2. The numpy dependency was removed (`np.unique` → an order-preserving
   de-duplication, `np.shape` → `len`, and the unused `numpy` genome
   representation → `list`), so the module runs under Pyodide.
3. `Grammar` accepts BNF text directly instead of only a file path.
4. A `GrammarError` is raised for grammars that cannot be used: symbols with no
   rule, and grammars whose depth table never converges (which previously caused
   an unbounded loop).
5. Dead comments and commented-out code were removed, and an internal
   tuple-unpacking bug in `reMap` was fixed.

The mapping algorithm itself is unchanged, and
`frontend/scripts/verify-engine.mjs` checks it against golden fixtures produced
by the unpatched `grape-bds` package (`frontend/tests/fixtures/`).

## DEAP — `deap_lite.py`

A trimmed subset of DEAP 1.4.4.

- License: GNU Lesser General Public License v3.0 —
  [`LICENSES/LGPL-3.0.txt`](../../../LICENSES/LGPL-3.0.txt), incorporating
  [`LICENSES/GPL-3.0.txt`](../../../LICENSES/GPL-3.0.txt) by reference
- Upstream: <https://github.com/DEAP/deap>

**Modifications**: only `Toolbox` and `Fitness` (from `deap/base.py`),
`MetaCreator` and `create` (from `deap/creator.py`) and `selRandom` /
`selTournament` (from `deap/tools/selection.py`) are kept, so the GRAPE
evolution loop can use DEAP's operators without numpy, scipy or moocore in the
browser. The optional numpy support and the `copyreg` pickling hooks were
dropped, and the metaclass registry was replaced by a small namespace object.

`deap_lite.py` remains available under the LGPL, as the LGPL requires for a
modified copy of the library. It is used here as a library linked into this
application, which the LGPL permits for a combined work; the file is shipped
unmodified in source form and its full text is included above.
