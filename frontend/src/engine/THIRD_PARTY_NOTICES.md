# Third-party notices — in-browser engine

The files in this directory are vendored so the GRAPE engine can run entirely
in the browser under Pyodide.

## GRAPE (`grape_core.py`)

`grape_core.py` is the GE Visualizer's instrumented copy of GRAPE's
`grape.py`. GRAPE is distributed under the BSD 3-Clause License, copyright BDS
Research Group at the University of Limerick.

The only changes for the browser build are removing the numpy dependency
(`np.unique`, `np.shape`, and the unused `numpy` genome representation are
replaced with pure-Python equivalents) and fixing an internal tuple unpack.
The mapping algorithm is unchanged; `frontend/scripts/verify-engine.mjs`
checks it against the golden grape-bds fixtures in `frontend/tests/fixtures/`.

Upstream: https://github.com/BDResearchGroup/GRAPE · paper:
https://www.mdpi.com/2624-6120/3/3/39

## DEAP (`deap_lite.py`)

`deap_lite.py` is a trimmed subset of DEAP 1.4.4, distributed under the GNU
Lesser General Public License v3 (LGPL-3.0). It vendors `Toolbox` and
`Fitness` from `deap/base.py`, `MetaCreator`/`create` from `deap/creator.py`,
and `selRandom`/`selTournament` from `deap/tools/selection.py`, so the GRAPE
evolution loop can use the real DEAP operators without numpy/scipy/moocore in
the browser.

Upstream: https://github.com/DEAP/deap · license:
https://www.gnu.org/licenses/lgpl-3.0.html

## Pyodide

The CPython runtime is provided by Pyodide (MPL-2.0), loaded from the copy of
the `pyodide` npm package in `frontend/public/pyodide/` (generated by
`frontend/scripts/copy-pyodide.mjs`).
